# Movie Recommendation System

## Project Overview
A movie recommendation application built using Python and machine learning techniques to suggest similar movies to users.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorization
- Cosine Similarity
- Streamlit

## How It Works
1. Load and process movie data.
2. Extract relevant movie features.
3. Convert text features into numerical vectors using TF-IDF.
4. Calculate similarity scores using cosine similarity.
5. Recommend similar movies based on the selected movie.

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Install dependencies:

   `pip install -r requirements.txt`

5. Run the application:

   `python -m streamlit run app.py`

## Project Files
- `app.py` — Main application.
- `movies.csv` — Movie dataset, if included.
- `requirements.txt` — Required Python libraries.
